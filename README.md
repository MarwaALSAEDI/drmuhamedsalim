# موقع عيادة د. محمد سالم عبدالسلام + لوحة التحكم

موقع عربي (RTL) سريع، مبني على **Node.js + Tailwind CSS v4**، مع لوحة تحكم بكلمة مرور
تتيح تعديل كل محتوى الموقع: صورة البداية، دوام العيادة، روابط الفيديو، صفحات الخدمات، والمقالات.

الخادم **لا يحتاج أي مكتبة وقت التشغيل** — Tailwind أداة بناء فقط، وملف الـCSS الناتج مبني وجاهز داخل `public/`.

---

## 1) التشغيل

على ويندوز: انقر مرتين على ملف **`تشغيل-الموقع.bat`**

أو من سطر الأوامر:

```bash
node server.js
```

ثم افتح:

| الرابط | الوصف |
|---|---|
| <http://localhost:3000/> | الموقع |
| <http://localhost:3000/admin/> | لوحة التحكم |

**كلمة المرور الأولى** تُنشأ تلقائياً عند أول تشغيل، وتُطبع في نافذة الأوامر
وتُحفظ في `data/ADMIN-PASSWORD.txt`.
بعد الدخول، غيّرها فوراً من تبويب **الإعدادات** (يُحذف الملف تلقائياً بعد التغيير).

## 2) لوحة التحكم — ماذا تستطيع أن تغيّر

| التبويب | يتحكم بـ |
|---|---|
| **الصفحة الرئيسية** | **صورة البداية (رفع صورة)**، السطر التمهيدي، العنوان H1، الفقرة، الأزرار، شارات الصورة، بطاقات «تعرّف على الطبيب»، مبادئ «لماذا تختار العيادة»، **مجالات الرعاية**، خطوات المراجعة، فقرة الضمان، Title/Meta |
| **دوام العيادة** | **أيام وأوقات العمل** — كل يوم: يعمل/مغلق + من/إلى. يظهر في الرئيسية والتذييل وصفحة الحجز، ويُرسل لمحركات البحث ضمن البيانات المنظمة |
| **الفيديوهات** | **إضافة روابط يوتيوب** مع عنوان وملخص وتفريغ نصي، وربط كل فيديو بصفحة خدمة |
| **الخدمات** | كل صفحة خدمة: الاسم، الرابط، الافتتاحية، الأقسام، الأسئلة الشائعة، الكلفة، Title/Meta، تاريخ المراجعة، علامة «مسودة» |
| **المقالات** | مقالات تثقيفية تظهر في صفحة التثقيف الطبي ومرتبطة بالخدمات |
| **معلومات العيادة** | الاسم، الهاتف، واتساب، العنوان، **رابط خرائط Google**، إنستغرام، الدومين، نصوص التذييل |
| **باقي الصفحات** | عن الطبيب (مؤهلات، جهات عمل، بحوث)، الضمان الصحي، الحجز، سياسة التحرير، الخصوصية |
| **طلبات المواعيد** | الطلبات الواردة: الاسم، الهاتف، **التاريخ والوقت المفضلان، سبب المراجعة**، ملاحظة — مع تغيير الحالة والحذف |
| **الإعدادات** | تغيير كلمة المرور، النسخ الاحتياطية والاسترجاع |

بعد أي تعديل اضغط **حفظ التغييرات** (أو `Ctrl + S`). التعديل يظهر على الموقع فوراً.

### رفع صورة البداية
تبويب «الصفحة الرئيسية» ← **رفع صورة جديدة** ← اختر الصورة (JPG / PNG / WebP، أقل من 8 ميغابايت)
← اكتب الوصف البديل ← **حفظ التغييرات**.
يُفضّل صورة عمودية واضحة بالسكراب الأسود، مضغوطة إلى أقل من 1 ميغابايت لسرعة أعلى.

### إضافة فيديو
تبويب «الفيديوهات» ← **+ إضافة فيديو** ← ألصق رابط يوتيوب ← عنوان + ملخص مكتوب
← اختر الخدمة المرتبطة ← **حفظ**.

**غلاف الفيديو يظهر تلقائياً** من يوتيوب، وتراه في اللوحة قبل الحفظ مباشرة.
تُقبل كل صيغ الروابط: `watch?v=` و `youtu.be` و `shorts` و `live` و `embed`، ومع أي إضافات في الرابط
(`?si=`، `&list=`، `&t=`، `app=desktop`)، وحتى لصق معرّف الفيديو وحده.

### غلاف الفيديو
داخل كل فيديو يوجد قسم **«صورة الغلاف»**:

- **اتركه فارغاً** ← يُستخدم غلاف يوتيوب تلقائياً.
- **ارفع صورة** ← لها الأولوية على غلاف يوتيوب. اضغط على المربع أو **اسحب الصورة وأفلتها** عليه.
- المقاس المثالي **1280×720** (نسبة 16:9)، بصيغة JPG أو PNG أو WebP وأقل من 8 ميغابايت.
- زر **«حذف الغلاف والرجوع لغلاف يوتيوب»** يلغي الصورة المرفوعة.

إذا كان الرابط من منصة أخرى (فيسبوك/إنستغرام)، ارفع غلافاً وستظهر بطاقة كاملة تفتح الرابط في تبويب جديد.
الغلاف المرفوع يُستخدم أيضاً في البيانات المنظمة (`VideoObject.thumbnailUrl`).

الفيديو لا يعمل تلقائياً ولا يُحمَّل إلا عند نقر الزائر (أفضل لسرعة الصفحة).

## 3) الملفات

```
site/
├─ server.js              الخادم والمسارات
├─ content.json           كل محتوى الموقع (يُعدَّل من لوحة التحكم)
├─ src/tailwind.css       مصدر التصميم: الألوان والحركات ومكوّنات الواجهة
├─ lib/
│  ├─ store.js            القراءة والحفظ والنسخ الاحتياطية وكلمة المرور
│  ├─ html.js             القالب العام والأيقونات والبيانات المنظمة (Schema)
│  ├─ components.js       مكوّنات الواجهة (Hero، ServiceCard، BookingForm…)
│  └─ pages.js            تركيب الصفحات من المكوّنات
├─ admin/                 لوحة التحكم (index.html + admin.js)
├─ tools/font.js          أداة تبديل الخط العربي
├─ public/                tailwind.css (مبني) + site.js + favicon
│  └─ fonts/              الخط العربي مستضاف محلياً (woff2)
├─ uploads/               الصور المرفوعة
└─ data/
   ├─ config.json         كلمة المرور (مشفّرة scrypt)
   ├─ requests.json       طلبات المواعيد
   └─ backups/            نسخة تلقائية قبل كل حفظ (آخر 40 نسخة)
```

### النسخ الاحتياطي اليدوي
انسخ المجلدات: `content.json` + `uploads/` + `data/`. هذه تكفي لاستعادة الموقع كاملاً.

## 3.5) التصميم — Tailwind CSS v4

كل التصميم مصدره ملف واحد: **`src/tailwind.css`** (الألوان، الحركة، ومكوّنات مثل `.btn` و`.card`).
ملف الـCSS الجاهز `public/tailwind.css` **مبني ومرفق**، فالموقع يعمل بدون تثبيت أي شيء.

```bash
npm install        # مرة واحدة فقط
npm run css        # بناء مضغوط
npm run css:watch  # بناء مستمر أثناء التعديل
```

### المكوّنات
الواجهة مبنية من مكوّنات قابلة لإعادة الاستخدام في **`lib/components.js`**:

`sectionHeading` · `hero` · `doctorIntro` · `serviceCard` · `servicesGrid` · `trustSection`
`specialties` · `articleCard` · `bookingForm` · `bookingSection` · `contactSection` · `faqBlock` · `pageHeader`

و`lib/pages.js` يركّب الصفحات منها، و`lib/html.js` فيه الترويسة والتذييل والأيقونات والبيانات المنظمة.

### الهوية اللونية
| اللون | القيمة | الاستخدام |
|---|---|---|
| Deep Navy | `#071C2C` | خلفية الهيرو والأقسام الداكنة والتذييل |
| Dark Navy | `#0B2638` | تدرّجات وبطاقات داكنة |
| Medical Teal | `#087F95` | الأزرار الأساسية والأيقونات |
| Bright Cyan | `#19C3DE` | لمسة التمييز: الأزرار على الداكن والمؤشرات |
| Soft Cyan | `#7EDBE8` | نصوص تمهيدية على الداكن |
| Off White | `#F5F9FA` | خلفيات الأقسام الفاتحة |
| Dark Text | `#102536` | العناوين |
| Muted Text | `#647785` | النص الثانوي على الفاتح |

التركواز **لمسة فقط**، والإيقاع البصري: هيرو داكن ← فاتح ← أبيض ← داكن ← أبيض ← حجز داكن ← تواصل أبيض ← تذييل داكن.

لتغيير الألوان كلها: عدّل `--color-navy-*` و`--color-brand-*` أعلى `src/tailwind.css` ثم `npm run css`.

### الخط والطباعة
الخط **IBM Plex Sans Arabic** مستضاف محلياً في `public/fonts/` — لا يعتمد على Google Fonts.
الأساس **17px** (‏16.5 على الموبايل)، ارتفاع السطر **1.85–1.95**، والأوزان 400/500/600/700 حقيقية.

تبديل الخط: `node tools/font.js "Cairo"` ثم `npm run css`.

### الحركة — مضبوطة ومقصودة
- ظهور تدريجي واحد عند التمرير (`.reveal`) عبر IntersectionObserver.
- الهيرو يدخل بـ`fade-up` خفيف مرة واحدة.
- البطاقات ترتفع 4px عند المرور، والأسهم تنزلق، والصور تكبر 3–4% فقط.
- الترويسة تقلّ ارتفاعاً وتكتسب ضبابية عند النزول.
- شارة «مفتوحة الآن» وتمييز يوم اليوم — تُحسب بتوقيت بغداد.
- **لا** يوجد: بارالاكس، ارتداد، تشغيل تلقائي للفيديو، نوافذ منبثقة، أو أشكال متحركة باستمرار.
- كل الحركة تتوقف مع `prefers-reduced-motion`.

## 4) صفحات الموقع

`/` · `/about/` · `/services/` · `/services/kidney-stones/` · `/services/varicocele/` ·
`/services/male-infertility/` · `/services/erectile-dysfunction/` · `/services/penile-implants/` ·
`/services/penile-filler/` · `/services/prostate/` · `/health-insurance/` · `/education/` ·
`/contact/` · `/editorial-policy/` · `/privacy/` · `/sitemap.xml` · `/robots.txt`

خريطة الروابط مطابقة لما ورد في دليل الـSEO، وكذلك عناوين Title وأوصاف Meta وH1 لكل صفحة.

### المنفَّذ تقنياً
- H1 واحد لكل صفحة، وTitle وMeta وcanonical مستقلة.
- بيانات منظمة: `WebSite`, `MedicalClinic` (مع أوقات الدوام), `Person`, `BreadcrumbList`,
  `MedicalWebPage` لصفحات الخدمات, `VideoObject` للفيديوهات.
- `sitemap.xml` يُبنى تلقائياً من الصفحات المنشورة، و`robots.txt` يمنع فهرسة `/admin` و`/api/`.
- المحتوى كامل في HTML (لا يعتمد على جافاسكربت للعرض)، وروابط داخلية قابلة للزحف.
- الصور بأبعاد ثابتة و`loading=lazy` لما هو أسفل الشاشة، وصورة البداية بأولوية عالية.
- الخرائط والفيديو لا تُحمَّل إلا عند الطلب، ولا يوجد تشغيل تلقائي ولا نوافذ منبثقة.
- زر الحجز ثابت أسفل شاشة الموبايل دون تغطية المحتوى.

### الأمان والخصوصية
- كلمة المرور مخزّنة بـ scrypt، وجلسة عبر كوكي HttpOnly مدتها 8 ساعات.
- إيقاف مؤقت بعد 6 محاولات دخول فاشلة.
- نموذج الحجز يجمع: الاسم، رقم التواصل، الوقت المفضل، ملاحظة قصيرة + موافقة صريحة — ولا يطلب تشخيصاً أو تقارير.
- لا يوجد Google Analytics ولا بكسلات إعلانية. إن أردت إضافة قياس لاحقاً، فليكن بعد مراجعة الخصوصية.

## 6) النشر على خادم

الموقع ملف واحد قابل للتشغيل، ويعمل على أي استضافة تدعم Node.js 18 فأحدث
(Railway، Render، VPS، …):

```bash
PORT=8080 node server.js
```

ضعه خلف Nginx أو Caddy لتفعيل HTTPS، واحرص على أن تكون المجلدات
`uploads/` و`data/` على تخزين دائم (لا يُمسح عند إعادة النشر).

> ملاحظة: لتشغيل دائم على VPS استخدم `pm2` أو خدمة systemd حتى يعمل الخادم بعد إعادة التشغيل.
